LINET TOURS & TRAVEL — MULTI-PAGE WEBSITE

Files:
- index.html: Home page
- tours.html: Tour packages listing
- masai-mara.html: Sample 3-day Maasai Mara tour detail page
- car-hire.html: Car hire page
- about.html: About the company
- contact.html: Contact and WhatsApp enquiry form
- styles.css and script.js: Shared design and functionality

To preview:
1. Extract all files from this ZIP into the same folder.
2. Open index.html in Chrome or another web browser.
3. Use the navigation menu to move between pages.

The enquiry form opens WhatsApp with the details prepared. It is not a live booking database or payment system.
Images are loaded from external image URLs, so an internet connection is needed to display them.
